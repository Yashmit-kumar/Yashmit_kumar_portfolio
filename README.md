## ✨ Features & Architecture

### 🚀 1. Visual Design & Micro-Animations
- **Cyber Neon & Deep Obsidian Theme**: Sleek dark-mode aesthetic with vibrant cyan (`#00f5d4`), electric violet (`#a855f7`), and emerald accents.
- **Interactive Particle & Neural Mesh Background**: Live HTML5 Canvas physics reacting to mouse velocity, hover gravity, and screen resize.
- **Theme Switcher**: Instant switching between **Cyber Neon**, **Obsidian Stealth**, and **Electric Violet** with `localStorage` memory.
- **Synthesized Audio Engine**: Zero-asset, futuristic Web Audio API sound synthesizer with gentle tones and instant mute/unmute control.
- **3D Holographic Card Tilt**: Interactive mouse tracking with spring-physics tilt on developer cards and projects.
- **Smooth Custom Cursor**: Dual-ring trailing follower cursor with hover scaling.

### 🎮 2. Interactive Live Playable Projects (Recruiters can test them directly!)
1. **Dictionary Web Application Simulator**:
   - Interactive live word search powered by the Free Dictionary API + local lexical offline engine.
   - Real-time definitions, phonetic transcription, and **voice pronunciation playback** (Web Speech Synthesis / Audio).
2. **PassGuard Cryptographic Password Generator**:
   - Customizable character length slider (6 to 36).
   - Character pool toggles (Uppercase, Lowercase, Numbers, Symbols).
   - Real-time cryptographic entropy score & color-coded strength meter.
   - One-click copy with toast notifications.
3. **Number Guessing Game (C Engine Web Port)**:
   - Retro arcade CRT terminal simulator.
   - Algorithmic random generation (1 to 100), adaptive feedback hints (*"Too High"*, *"Too Low"*, *"Boiling Hot"*), and attempt scoreboard.

### 💻 3. Interactive Developer Hacker CLI (`~` or `>_ CLI`)
- Press the **`~` (Tilde)** key or click the **`>_ CLI`** button to open an interactive developer terminal.
- Commands supported:
  - `help` — Lists all commands
  - `about` — Developer bio and background
  - `skills` — Technical skill breakdown
  - `projects` — Projects summary
  - `education` — University & degree info
  - `certs` — Industry certifications
  - `contact` — Direct channels and links
  - `hire` — Why hire Yashmit Kumar
  - `theme [cyber|obsidian|electric]` — Change theme
  - `matrix` — Matrix digital rain alert
  - `date`, `clear`, `sudo`, `exit`

## 🏃 How to Run Locally

### Option A: Open directly in your browser
Simply double-click `index.html` or right-click and choose **Open With > Google Chrome / Microsoft Edge / Brave / Firefox**.

### Option B: Run with Python or VS Code Live Server
In your terminal, navigate to the folder and run:

```bash
# Using Python 3:
python -m http.server 3000

# Then open in your browser:
http://localhost:3000
```
